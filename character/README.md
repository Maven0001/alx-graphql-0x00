# GraphQL Queries - Specific Character by ID

This directory contains GraphQL queries to fetch individual characters from the Rick and Morty API using the `character(id: ID!)` field.

## Endpoint

https://rickandmortyapi.com/graphql

## Queries

- Fetch character with ID 1, 2, 3, and 4
- Fields requested: id, name, status, species, type, gender
